ERArchive v0.42 — 관리자/팀원 뉴스 통일 · 화면 밀도 및 갱신 최적화

적용: 프로그램 종료 → 05_backup.bat 백업 → ZIP의 er-archive 내용을 기존 폴더에 덮어쓰기 → 실행 → Ctrl+F5.
기존 data/.venv/모델/수집폴더·인증키는 유지합니다. 추가 설치나 자료 재수집은 필요 없습니다.

1. 뉴스 구성 통일
관리자와 팀원 모두 상단 헤드라인, 아래 왼쪽 주요 언론 기사/오른쪽 철강 전문지 구성을 사용합니다. 전문지는 스틸데일리 위, 페로타임즈 아래입니다. 관리자에게만 뉴스 설정·수집·미리보기·기사 선별/제외·전문지 수집 기능이 표시됩니다. 좁은 화면에서는 전문지가 아래로 내려갑니다.

2. 동향메모 카드 압축
카드 여백 16→12px, 본문 미리보기 최대 14→9줄, 줄 간격 1.85→1.65로 줄였습니다. 긴 본문은 전체 내용 보기에서 확인합니다. 원본 줄바꿈과 저장 내용은 그대로 유지합니다.

3. 기업실적 세로 공간 절약
결합 차트의 실제 그리기 영역을 낮추고 최대 높이를 360→240px로 조정했습니다. 화면 높이에 따라 180~240px 범위를 사용하며 축/범례 글씨 크기는 유지합니다. 조회 조건·회사명·차트 여백과 실적 표 셀 높이도 축소해 표 시작 위치를 앞당겼습니다. 분기/연간 버튼은 왼쪽, 안내는 오른쪽을 유지합니다. 첫 화면에서 보이는 범위는 화면 해상도와 브라우저 배율에 따라 달라집니다.

4. 반복 갱신 최적화
- 뉴스 자동 갱신: 응답 내용이 그대로면 전체 목록을 다시 그리지 않습니다. 검색 입력 중에는 자동 갱신을 미루고, 응답 대기 중 입력을 시작해도 입력값을 덮어쓰지 않습니다. 펼친 이슈 기사 목록을 유지합니다.
- 기업실적 자동 갱신: 수집 진행 건수만 바뀌면 상태 문구만 갱신하고 차트/표를 다시 그리지 않습니다. 실적 값이 바뀌면 갱신하며 조회 조건 입력 중에는 화면 교체를 미룹니다.
- 수동 조회를 시작하면 기존 예약 갱신을 정리하고, 다른 탭으로 이동한 뒤 도착한 오래된 응답은 적용하지 않습니다.
- 삭제된 실적 증감률 탭의 불필요한 화면 코드/스타일을 정리했습니다. 서버 계산·기존 저장자료·기사 분류/묶음 기준은 변경하지 않았습니다.

검증
Python 전체 180개 테스트: 177개 통과, 기존 조건 3개 건너뜀.
뉴스/금융/메모/일정 표시 및 자동 갱신 JavaScript 검사 통과. 변경 없는 응답에서 재렌더링 생략, 입력 중/응답 대기 중 입력 보호, 펼친 기사 유지, 오래된 응답 차단을 검사했습니다.
이 환경에는 실행 가능한 브라우저가 없어 실제 브라우저의 화면 배치와 사용자 DART 인증키 연결은 확인하지 못했습니다.
