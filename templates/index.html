홍보물 등록

여러 홍보물을 함께 선택하면 백그라운드에서 순서대로 인식합니다. 완료 후 묶음을 확인하고 한 번에 게시하세요.

선택 파일은 파일명 순으로 정렬합니다. 아래 미리보기에서 순서를 확인·변경하세요.

JPG · PNG · WebP / 장당 15MB, 최대 20장·총 60MB

원본 저장 후 사내 OCR을 실행합니다. OCR이 없거나 실패해도 직접 분류할 수 있습니다.

묶음 확인 · 일괄 등록

각 페이지 오른쪽 위 ×를 누르면 게시에서 제외되고 다시 누르면 복원됩니다. 페이지 카드를 끌어서 같은 묶음의 순서를 바꾸거나 다른 묶음으로 옮기세요. 맨 아래 영역에 놓으면 새 묶음으로 분리됩니다. 본문 교정은 임시등록 후 자료 상세 화면에서 할 수 있습니다.

수집폴더 설정
이 폴더에 이미지 또는 HWP를 넣으면 복사가 멈춘 뒤 자동으로 가져옵니다. 원본은 이동하거나 삭제하지 않습니다.
폴더 안에 이미지 또는 HWP를 바로 넣으세요. HWP는 일정 검토 화면에서 확인합니다. 하위 폴더는 읽지 않습니다. 같은 내용의 파일은 이름이 달라도 건너뜁니다. 수집 후 관리자 확인을 거쳐 게시합니다.
