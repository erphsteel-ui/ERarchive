ER Archive update

1. Stop the server and back up your existing data.
2. Copy the files in this folder into the existing program folder. Keep data and .venv.
3. Run 00_remove_old_files.bat once from the program folder.
4. Start the server as usual. Retired news records, news credentials and preview images will be deleted on startup.
5. Refresh the browser with Ctrl+F5.

The shortcut created in Windows startup and older Korean-named widget instructions can be deleted manually. Existing schedule and publication data are preserved.
