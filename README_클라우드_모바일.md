# 모바일·클라우드 버전 안내

이 파일은 2026-11-10 일정 단어 줄바꿈 버전을 기반으로 모바일 화면과 클라우드 배포 구성을 적용한 작업본입니다. 서버 설치와 백업은 `CLOUD_DEPLOY.md`를 먼저 읽으세요. 기존 `README_먼저읽기.md`와 업데이트 안내에는 이전 자동 인식 기능 설명이 남아 있으므로 이 문서가 우선합니다.

- 핵심 화면은 일정, 홍보물, 법률·사규입니다. 모바일 관리자 `+`에서 일정을 추가하거나 이미지/PDF를 제목 등과 함께 수동 게시합니다. 일정 삭제는 게시 제외 방식입니다.
- 자동 OCR/VL, 자동 일정 추출과 수집폴더 감시는 실행하지 않습니다. 과거 OCR 본문, 원본 파일, 대기열과 기존 DB 구조는 보존됩니다. 이전 대기열은 자동으로 처리되지 않습니다.
- Reader는 검색과 열람만 할 수 있습니다. 기본 상태에서는 로그인하지 않은 방문자도 공개된 자료를 읽을 수 있습니다. 외부 접속 제한과 HTTPS는 `CLOUD_DEPLOY.md`를 참고하세요.
- 법령 검색과 원문 가져오기는 국가법령정보센터 OC 설정과 외부 연결이 필요합니다. 기존 사규 전문 열람은 별도로 동작합니다.
- PDF는 브라우저의 내장 뷰어를 사용하므로 기기에 따라 원본 열기 또는 다운로드가 필요할 수 있습니다. 홈 화면 추가는 지원하지만 오프라인 캐시는 제공하지 않습니다.
- 기존 `data/`는 이 ZIP에 포함되지 않습니다. 이관 시 기존 서버를 중지하고 DB·원본 파일·세션 키를 포함한 `data/` 전체를 백업하여 영구 볼륨에 복원하세요.
