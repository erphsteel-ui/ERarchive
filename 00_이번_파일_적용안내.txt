ER 아카이브 업데이트 (2026-11-10)

일정 카드에 은은한 배경, 차콜색 본문, 주체 배지를 적용했습니다. 다섯 개 분류의 자동 분류와 직접 수정, 달력 범례와 A3 인쇄에도 반영됩니다. 단체교섭·노사협의회·동향 탭 및 VL 정밀 인식은 제거되어 있습니다.

1. 실행 중인 서버를 종료하고 기존 자료를 백업합니다.
2. 압축 안의 파일을 기존 프로그램 폴더에 덮어씁니다. data, .venv, 수집폴더는 삭제하지 마세요.
3. 기존 폴더에 남은 07_check_vl.bat는 더 이상 사용하지 않으므로 삭제하세요. 이전 기능 코드 파일은 덮어쓰기만으로 자동 삭제되지 않지만 서버에서 불러오지 않습니다.
4. 03_start_team.bat를 실행하고 브라우저에서 Ctrl+F5를 누릅니다.

일반 열람 IP 제한은 기본 해제됩니다. 관리자 기능은 로그인해야 합니다. 운영 데이터와 비밀번호는 압축에 포함하지 않았습니다.
